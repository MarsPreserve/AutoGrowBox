# Mars Preserve website

Responsive static website based on the supplied Mars Preserve Auto Grow Box concept image.

## Preview locally
Open `index.html` in a browser. The image asset must remain at `assets/mars-preserve-concept.png`.

For a local web server, run:
```bash

python3 -m http.server 8000

```
