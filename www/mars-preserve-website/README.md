# Mars Preserve website

Responsive static website based on the supplied Mars Preserve Auto Grow Box concept image.

## Preview locally
Open `index.html` in a browser. The image asset must remain at `assets/mars-preserve-concept.png`.

For a local web server, run:
```bash
python -m http.server 8000
```
Then open http://localhost:8000.

## Publish with GitHub Pages
1. Add `index.html`, the `assets/` folder, and this README to the `marspreserve` repository.
2. In GitHub, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the branch containing these files and the `/ (root)` folder, then save.
4. GitHub Pages will provide the published URL after deployment.

The website links to https://github.com/marspreserve. It does not push files or change repository settings automatically; that requires authenticated access to the GitHub account.
